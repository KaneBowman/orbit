Why Orbit

不是另一个笔记软件，
而是你的第二大脑。

大多数工具帮你「记下来」。Orbit 更关心，想法之间如何发生关系，以及你如何再次找到它们。

把工作流，写成插件

开放的 TypeScript API，从日历到 AI 摘要，一切都可以插拔。你的工具，应该按你的方式工作。

weekly-review.tsTypeScript
export const weeklyReview = definePlugin({
  name: 'weekly-review',
  onRun: async ({ notes }) => {
    const week = notes.since('7d')
    return summarize(week, {
      style: 'gentle',
      links: true
    })
  }
})

How it works

捕捉。连接。
然后，看见全貌。

Orbit 不要求你先建立完美的分类体系。随手写下，剩下的交给链接、搜索和每天一次的回顾。

从混乱中开始，也没关系。
Orbit 会陪你慢慢找到结构。

Built to extend

为扩展而生。
或者，只为你而生。

Orbit 的核心保持克制，边界保持开放。用熟悉的 TypeScript 编写插件，连接自己的 API、自动化流程和 AI 工作流。

  • 完整的类型定义与本地调试工具
  • 插件运行在隔离沙箱中，权限透明
  • 一条命令，发布到社区插件市场
